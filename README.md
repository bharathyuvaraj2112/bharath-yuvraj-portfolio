# Bharath Yuvraj — Portfolio

A modern personal portfolio built with Next.js, React, TypeScript and Tailwind CSS for an AI & Machine Learning student and full-stack developer.

## Features

* **Responsive Design**: Mobile-first responsive layout optimized for all viewport sizes (320px to 1440px+).
* **Dark Mode Aesthetic**: High-contrast, metallic dark-mode design system with custom micro-interactions.
* **Hero Showcase**: Profile photo visual, availability status badge, and key call-to-actions.
* **Projects Showcase**: Interactive project cards with category filtering (`AI / ML`, `Full Stack`, `Hardware / IoT`) and detailed modal view.
* **Skills Section**: Organized across 6 technical domains with honest competency badges.
* **Education Timeline**: Chronological academic timeline covering B.Tech AIML, Intermediate (Class XII), and Secondary School (Class X).
* **Certifications**: Verified training programs and skill assessments.
* **Achievements**: Milestone timeline covering hackathons, coding practice, and academic achievements.
* **Contact Form**: Interactive contact section with client-side validation and direct email link.
* **SEO Foundations**: Complete page titles, Open Graph tags, and semantic HTML5 structure.

## Tech Stack

* **Framework**: Next.js 16 (App Router)
* **Library**: React 19
* **Language**: TypeScript
* **Styling**: Tailwind CSS v4 & Modern CSS
* **Animations**: Framer Motion
* **Icons**: Lucide React Icons & Custom SVGs
* **Version Control**: Git & GitHub
* **Hosting**: Vercel

## Local Development

To run this project locally:

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Test production build
npm run build
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## Deployment

The website is continuously deployed on **Vercel**. Any commit pushed to the `main` branch on GitHub automatically triggers a production build and deployment.
